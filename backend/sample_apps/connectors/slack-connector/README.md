# Slack Connector

Send security alerts to Slack channels and ingest Slack audit logs.

## Features

- Real-time alert notifications to Slack
- Slack audit log ingestion
- Channel activity monitoring
- User engagement tracking
- Message volume analytics

## Configuration

- **Webhook URL**: Slack incoming webhook URL
- **Channel**: Target channel for alerts (e.g., #security-alerts)
- **Bot Token**: Slack bot token for API access
- **Alert Severity**: Minimum severity level to forward

## Permissions Required

- `read:alerts` - Read security alerts
- `write:data` - Write Slack audit logs to indexes

## Dashboard

Monitor Slack activity with:
- Message volume timeline
- Active channels count
- User engagement metrics

## Installation

1. Create a Slack app at api.slack.com
2. Generate webhook URL and bot token
3. Install connector from App Store
4. Configure Slack credentials
5. View dashboard
