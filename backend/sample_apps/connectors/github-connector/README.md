# GitHub Connector

Monitor repository events, pull requests, and security alerts from GitHub.

## Features

- Repository event tracking
- Commit activity monitoring
- Pull request metrics
- Security alert ingestion
- Contributor analytics

## Configuration

- **GitHub Token**: Personal access token or GitHub App token
- **Organization**: GitHub organization name
- **Repositories**: Comma-separated list of repos (or * for all)
- **Webhook Secret**: Secret for webhook validation

## Permissions Required

- `read:data` - Read indexed data
- `write:data` - Write GitHub events to indexes

## Dashboard

Track development activity with:
- Commit activity timeline
- Open pull requests count
- Top contributors
- Security alerts

## Installation

1. Generate GitHub personal access token
2. Install connector from App Store
3. Configure GitHub credentials
4. Optionally set up webhooks for real-time events
5. View dashboard
